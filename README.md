About This Repository

Welcome to my Artificial Intelligence Studies repository!

This repository documents my learning journey in Artificial Intelligence, Machine Learning, Deep Learning, and AI Engineering.

My goal is to build a strong theoretical foundation while developing practical skills through coding exercises, experiments, and real-world projects.

I will use this repository to organize my notes, document what I learn, share implementations, and track my progress and it may help those find themselves in a similar situation.

📝 **Study Method**

For each topic, I aim to follow this learning process:

- Understand: Study the theoretical concepts.
- Document: Write notes and explanations in my own words.
- Implement: Reproduce concepts using Python.
- Experiment: Modify implementations and test different approaches.
- Reflect: Document what worked, what did not, and what I learned.
